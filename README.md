# stalwart-mcp-readonly

Purpose: design an MCP server to search and read Stalwart mail via JMAP and export
raw .eml threads with manifests and SHA-256 hashes.

**Read-only by design. No mail data or secrets in this repo.**

Status: **design phase** — documentation only; no server implementation yet.
See the [design studies](docs/studies/README.md) for cited findings, proposals,
security boundaries, and unresolved questions.
