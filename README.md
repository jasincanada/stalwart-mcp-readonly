# stalwart-mcp-readonly
Read-only, evidence-grade MCP server for Stalwart Mail Server (JMAP). Design studies and implementation. No mail data in this repo.

Studies:

- [Stalwart API study](docs/stalwart-api.html) covers the mail JMAP door and the management JMAP door for this server.
- [App ideas](docs/stalwart-app-ideas.html) lists the programs worth building on those two doors.
- [App password web page](docs/stalwart-app-passwords.html) describes how a signed-in user can create, list, and revoke app passwords.
